# Prozesse

## ps

```bash
ps -ef
```

### Bedeutung

Zeigt laufende Prozesse an.

### Beispiel

```bash
ps -ef | grep main.py
```

---

## kill

```bash
kill PID
```

### Bedeutung

Beendet einen laufenden Prozess.

### Beispiel

```bash
kill 4809
```

---

## top

```bash
top
```

### Bedeutung

Zeigt laufende Prozesse und die Systemauslastung in Echtzeit an.

### Beispiel

```bash
top
```
