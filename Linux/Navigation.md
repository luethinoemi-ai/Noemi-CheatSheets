# Navigation

## pwd

```bash
pwd
```

**Bedeutung:**

Zeigt den aktuellen Ordner an.

**Beispiel:**

```bash
pwd
```

Ausgabe:

```text
/home/user/Projects
```

---

## ls

```bash
ls
```

**Bedeutung:**

Zeigt den Inhalt eines Ordners an.

---

## ls -la

```bash
ls -la
```

**Bedeutung:**

Zeigt alle Dateien und Ordner an, auch versteckte Dateien.

**Beispiel:**

```text
.git
.gitignore
```

---

## cd

```bash
cd Ordnername
```

**Bedeutung:**

Wechselt in einen anderen Ordner.

**Beispiel:**

```bash
cd Projects
```
