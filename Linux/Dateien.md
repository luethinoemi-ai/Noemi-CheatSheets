# Dateien

## touch

```bash
touch test.txt
```

**Bedeutung:**

Erstellt eine neue leere Datei.

---

## nano

```bash
nano test.txt
```

**Bedeutung:**

Bearbeitet eine Datei im Terminal.

---

## cat

```bash
cat test.txt
```

**Bedeutung:**

Zeigt den Inhalt einer Datei an.

---

## less

```bash
less test.txt
```

**Bedeutung:**

Zeigt eine Datei mit Scrollfunktion an.

**Beenden:**

```text
q
```

---

## head

```bash
head test.txt
```

**Bedeutung:**

Zeigt die ersten 10 Zeilen einer Datei.

---

## tail

```bash
tail test.txt
```

**Bedeutung:**

Zeigt die letzten 10 Zeilen einer Datei.
