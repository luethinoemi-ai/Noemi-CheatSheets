# Ordner

## mkdir

```bash
mkdir test
```

**Bedeutung:**

Erstellt einen neuen Ordner.

---

## rmdir

```bash
rmdir test
```

**Bedeutung:**

Löscht einen leeren Ordner.

---

## cp

```bash
cp a.txt b.txt
```

**Bedeutung:**

Kopiert eine Datei.

---

## mv

```bash
mv alt.txt neu.txt
```

**Bedeutung:**

Verschiebt oder benennt Dateien um.

---

## rm

```bash
rm test.txt
```

**Bedeutung:**

Löscht eine Datei.

---

## rm -r

```bash
rm -r test
```

**Bedeutung:**

Löscht einen Ordner inklusive Inhalt.
