# Netzwerk

## ping

```bash
ping google.ch
```

### Bedeutung

Prüft, ob ein Ziel im Netzwerk erreichbar ist.

### Beispiel

```bash
ping google.ch
```

---

## ssh

```bash
ssh user@server
```

### Bedeutung

Stellt eine Verbindung zu einem anderen Rechner oder Server her.

### Beispiel

```bash
ssh noemi@192.168.1.100
```
