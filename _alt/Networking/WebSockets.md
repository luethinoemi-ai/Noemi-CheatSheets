# WebSockets

## Problem

HTTP

Anfrage
↓
Antwort
↓
Verbindung beendet

Bei Echtzeitdaten muss ständig neu gefragt werden.

## Lösung

WebSocket

Verbindung bleibt offen.

Client ↔ Server

Beide Seiten können jederzeit Daten austauschen.

## Anwendungen

- Chats
- Echtzeitdaten
- Simulatoren
- Fahrgastanzeigen

## Merksatz

HTTP = Frage stellen

WebSocket = Gespräch führen
