# HTTP

## Was ist HTTP?

HTTP = Hypertext Transfer Protocol

HTTP funktioniert nach dem Request-Response-Prinzip.

Client
↓ Request
Server
↓ Response
Client

## URL

URL = Uniform Resource Locator

Bestandteile:

- Schema
- Domäne
- Port
- Pfad
- Argumente
- Anker

DNS:

Domain → IP-Adresse

## Ports

HTTP = 80

HTTPS = 443

## HTTP Methoden

GET
→ Daten lesen

POST
→ Daten senden

PUT
→ Daten ersetzen

PATCH
→ Daten teilweise ändern

DELETE
→ Daten löschen

## Statuscodes

200 = OK

404 = Not Found

500 = Internal Server Error
