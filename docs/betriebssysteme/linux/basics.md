# Linux Basics

## Was ist Linux?

Linux ist ein Open-Source-Betriebssystem und wird häufig für:

- Server
- Cloud-Systeme
- Embedded-Systeme
- Softwareentwicklung

eingesetzt.

---

## Wichtige Konzepte

### Alles ist eine Datei

In Linux werden viele Ressourcen als Dateien behandelt:

- Normale Dateien
- Ordner
- Geräte
- Prozesse

---

### Verzeichnisstruktur

```text
/
├── home
├── etc
├── var
├── usr
└── tmp
```

### Wichtige Ordner

| Ordner | Bedeutung |
|----------|----------|
| / | Root-Verzeichnis |
| /home | Benutzerverzeichnisse |
| /etc | Konfigurationsdateien |
| /var | Logs und variable Daten |
| /tmp | Temporäre Dateien |
| /usr | Programme und Bibliotheken |

---

## Terminal

Das Terminal ermöglicht die Steuerung des Systems über Befehle.

Beispiel:

```bash
pwd
ls
cd Downloads
```

---

## Dateirechte

Linux verwendet:

```text
r = read
w = write
x = execute
```

Beispiel:

```text
-rwxr-xr-x
```
