# JSON

JSON = JavaScript Object Notation

JSON ist ein einfaches Datenformat zum Speichern und Austauschen von Daten.

## Beispiel

```json
{
  "name": "Noemi",
  "age": 18
}
```

## Eigenschaften

- leicht lesbar
- leicht verarbeitbar
- häufig bei APIs verwendet

## Einsatzgebiete

- Web APIs
- Simulatoren
- Konfigurationsdateien
- Datenaustausch

## Merksatz

JSON = Datenformat für Informationen.
